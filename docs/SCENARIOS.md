# 夜班反例

18位员工各有10月1日22点进、10月2日06点出。02点至03点休息，实际7小时，前两小时是假日3倍，次日5小时正常1倍，20元时薪合计220元。直接把整个夜班按归属日计假日会错算420元。脏批额外含缺时薪、冲突打卡、BOM、短行、空行与重复表头。
